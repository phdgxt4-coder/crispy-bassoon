# إصلاحات منصة التفوق — فرع مراجعة

هذا الفرع منفصل عن `main`، وطلب الدمج ما زال مسودة. لم تُنشر التغييرات إلى GitHub Pages أو Firebase؛ الموقع الحي لا يتغير قبل الدمج والنشر المقصود.

## قبل الدمج أو النشر

1. استبدل `REPLACE_WITH_ADMIN_UID` في `index.html` و`firestore.rules` بمعرّف حساب الأدمن من Firebase Authentication. يجب أن يتطابق النص في الملفين؛ تركه كما هو يمنع صلاحيات الأدمن. الـUID ليس كلمة مرور، لكنه معرّف عام ضمن الكود. إخفاء دور الأدمن عن الواجهة يحتاج لاحقًا Custom Claims وخدمة إدارية موثوقة.
2. غيّر كلمات مرور حسابات الأدمن والطلاب التي سبق مشاركتها، ودوّر مفاتيح التوقيع المكشوفة. إزالة الملفات من شجرة المشروع لا تمحوها من تاريخ Git؛ تنظيف التاريخ بعد التدوير عملية منفصلة ومدمرة ويجب تخطيطها.
3. نظّف أي أسرار قديمة في `config/site` في Firebase قبل نشر القواعد. بعد النشر، سجّل دخول الأدمن أولًا وانتظر ترحيل الحقول الخاصة القديمة من `students` و`leaderboard` و`qb_battles` قبل دخول الطلاب؛ قراءة لوحة الشرف القديمة تُحجب حتى التنظيف. قد يستهلك ذلك حصة قراءة/كتابة حسب عدد السجلات. اختبر التغييرات أولًا على مشروع تجريبي، ثم انشر `firestore.rules` يدويًا.
4. دليل `publicProfiles` يحفظ الاسم ووقت التحديث فقط ويُحدّث عند التسجيل أو أول دخول بعد نشر التعديل. البحث حاليًا محدود بأول 200 سجل ولا يحتوي ترقيم صفحات.
5. وضع HTML المخصص يقبل ملفًا ذاتي الاحتواء حتى 600KB ويخزنه في Firestore، لا Storage. يوفر مشغلًا معزولًا فقط؛ لا يتضمن لعبة PUBG أو خادمًا أو مزامنة لاعبين.
6. حزمة ZIP لا تتضمن APK/AAB. فرع المراجعة يبقي ملفات APK/AAB الصالحة وروابطها دون تعديل، ويحذف ملف APK غير صالح بحجم بايت واحد وملفات التوقيع. بسبب انكشاف مفتاح التوقيع، راجع الإصدارات السابقة واتبع إجراء تدوير المفتاح المناسب قبل إصدار نسخة جديدة.

## معالجة التحديثات المتكررة

أزيلت إعادة التحميل القسرية عند تغيّر `cacheBust` وعند تبدّل Service Worker، وأُلغي فحص التحديث كل خمس دقائق و`skipWaiting` التلقائي. يعرض التطبيق تنبيهًا غير حاجب ويترك التحديث للزيارة/إعادة التحميل التالية التي يختارها المستخدم. كما أصبح حذف الكاش محصورًا في مفاتيح `eltafawoq-*` ونطاق Service Worker الخاص بالموقع.

## التحقق المحلي

- فحص `node --check` لـ21 كتلة JavaScript مضمّنة في `index.html` وملفات الألعاب الخمسة عشر.
- ترجمة قواعد Firestore على Emulator واجتياز 42 حالة سماح/رفض، بينها دليل الأسماء العام ومنع إضافة الهاتف إليه.
- اجتياز `git diff --check` والتحقق من عدم وجود استدعاءات تنفيذية لـFirebase Storage في `index.html`.

هذه الاختبارات لا تثبت صحة كل تدفقات الإنتاج، ولم تُنشر القواعد أو الصفحة تلقائيًا. القواعد وحدها لا تمنع تزوير درجات أو XP يحسبها المتصفح؛ يلزم تحقق خادمي موثوق لأي جوائز أو صلاحيات حساسة.
