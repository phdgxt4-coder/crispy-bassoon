# إصلاحات منصة التفوق — فرع مراجعة

هذا الفرع منفصل عن `main`. لم يتم دمجه أو نشره إلى GitHub Pages أو Firebase؛ لا يتغير الموقع الحي إلا بعد الدمج/النشر المقصود.

## قبل الدمج أو النشر

1. استبدل `REPLACE_WITH_ADMIN_EMAIL` في `index.html` و`firestore.rules` ببريد حساب Firebase Auth إداري مخصص ومتطابق في الملفين. تركه سيمنع دخول لوحة الأدمن.
2. غيّر كلمات المرور التي سبق مشاركتها، ودوّر أي مفاتيح أو بيانات توقيع مكشوفة. حذف ملف من الفرع لا يمحو النسخ في تاريخ Git؛ تنظيف التاريخ عملية منفصلة ومدمرة يجب تخطيطها بعد تدوير المفاتيح.
3. نظّف حقول الأسرار القديمة من `config/site` في Firebase قبل نشر القواعد، واختبر التغييرات أولًا على مشروع تجريبي.
4. وضع HTML المخصص يقبل ملفًا مستقلًا واحدًا حتى 600KB ويخزنه في Firestore، لا Storage. يوفر مشغلًا معزولًا فقط؛ لا يحتوي لعبة PUBG، ولا خادمًا أو مزامنة لاعبين.
5. حزمة ZIP المرفقة لا تتضمن APK/AAB. فرع المراجعة يبقي ملفات APK/AAB الصالحة وروابطها دون تعديل، ويحذف ملف APK غير صالح بحجم بايت واحد وملفات التوقيع. بسبب انكشاف مفتاح التوقيع، تعامل مع الإصدارات الحالية كمحتمل تعرضها للخطر، وراجعها/أعد إصدارها بعد اتباع إجراء تدوير المفتاح المناسب.

## التحقق المحلي

- فحص نحو كتل JavaScript الست في `index.html` وملف `sw.js`.
- التحقق من ملفات JSON.
- ترجمة قواعد Firestore باستخدام Emulator.
- اجتياز 15 اختبار صلاحيات مختارًا، تشمل الأسرار وعضوية الرسائل وإيقاف الميزات وقراءة ملف اللعبة فقط عند تفعيل وضعه.

هذه الاختبارات ليست تدقيقًا شاملًا للإنتاج؛ النقاط ونتائج الامتحانات ولوحة الترتيب ما زالت تحتاج تحققًا خادميًا موثوقًا لمنع التلاعب.
